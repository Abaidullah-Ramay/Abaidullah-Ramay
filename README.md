### 🚀 Selected Projects

#### Automotive Financing & Banking MCP Agent

A conversational application that connects vehicle inventory and banking data to help users compare financing options and calculate down payments.

- Built with **FastMCP, LangGraph, FastAPI, and Streamlit**.
- Exposes tools through **Streamable HTTP and stdio**.
- Uses **LangSmith** to trace agent execution and evaluate latency and cost.

#### Multimodal Document Intelligence Engine

A RAG application for querying enterprise documents containing text, tables, and diagrams.

- Combines **LayoutLMv3** for document layout processing, **ColPali** for visual retrieval, and **GPT-4o** for multimodal understanding and answer generation.
- Uses **ChromaDB** for indexing and **FastAPI** for backend integration.
- Provides page-level retrieval and inline visual references so users can inspect the source material behind an answer.

#### Codebase Intelligence & GitHub Q&A Agent

An engineering assistant for asking questions about GitHub repositories and exploring dependencies across files.

- Uses **Tree-Sitter** for AST-based code chunking.
- Combines **pgvector** semantic retrieval with branch-aware indexing.
- Built with **LangChain, PyGithub, FastAPI, and React**.

Alongside AI development, I work on the backend performance and reliability of deployed applications.

- Reducing database round trips for recent scans from **three to one**.
